# Weight Loss Prediction with ANN 🤖

## 📌 About the Project

This project uses an Artificial Neural Network (ANN) to predict weight loss outcomes based on lifestyle habits such as diet, exercise, sleep, and stress levels.

## 🎯 Input Features

- Diet Score
- Exercise Hours
- Sleep Hours
- Stress Level

## 💻 Technologies Used

- Python
- Pandas
- NumPy
- TensorFlow & Keras

## ⚙️ Model

- Artificial Neural Network (ANN)
- ReLU and Sigmoid Activation Functions
- Adam Optimizer
- Binary Classification

## 🌍 Real-World Applications

- Fitness Tracking Apps
- Wellness Platforms
- AI Health Assistants
- Personalized Diet Recommendations

## 📊 Prediction

The model predicts whether a person is:

- Likely to Achieve Weight Loss
- Unlikely to Achieve Weight Loss

## 🚀 Learning Outcome

Gained practical experience in ANN, data preprocessing, model training, and machine learning predictions using Python.
